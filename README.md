# Frontend_Atlas
## Описание проекта:

**Атлас народов России** — это веб-платформа для изучения народов Российской Федерации.

Главная страница представляет собой интерактивную карту России. Пользователь может выбрать регион и увидеть список народов, проживающих в нём, а затем перейти к статье с информацией о выбранном народе.

Платформа также позволяет зарегистрированным пользователям создавать дополнительные материалы к основной статье (факты, традиции, истории, фотографии). Все пользовательские материалы проходят модерацию перед публикацией.

Проект направлен на создание единого удобного пространства для структурированного представления информации о народах России.

## Запуск проекта

### Требования

- Node.js 18+
- npm

### Установка

```
# Клонировать репозиторий
git clone <repository-url>

# Перейти в папку проекта
cd atlas-frontend

# Установить зависимости
npm install
```

### Запуск в режиме разработки

```
npm run dev
```

После запуска приложение будет доступно по адресу:

```
http://localhost:3000
```

### Сборка для продакшена
Для сборки production-версии нужно выполнить команду:
```
npm run build
```
После выполнения команды в папке dist будет создана оптимизированная сборка проекта, готовая к развертыванию на сервере.
